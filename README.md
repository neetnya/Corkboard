# 截图线索板 · Corkboard

> 一个 Windows 桌面小工具：在游戏/工作过程中随手截图，把截图像**侦探线索板**一样钉在白板上——拖拽、缩放、画圈、贴便条，随时回顾推理，不用反复切窗口。

## 功能特性

| 功能 | 说明 |
|---|---|
| **双全局快捷键** | 局部截图（框选）与全屏截图，均可在设置中自定义 |
| **框选截图** | QQ/微信式全屏遮罩框选，松手即存，**不做二次确认** |
| **全屏截图** | 类似 PrintScreen，按下即存（仅主屏） |
| **分组管理** | 分组即文件夹，截图存入「当前分组」，支持新建/重命名/删除 |
| **白板** | 图片自由拖拽、点击置顶、滚轮以鼠标为锚缩放、1px 黑色边框 |
| **层级规则** | 便条层级**恒定高于**图片；图片与便条各自独立排序 |
| **便条** | 白底黑字文本框，可拖拽、右下角缩放、双击编辑 |
| **图片编辑** | 右键「编辑」→ 图片进入**独立编辑窗口**，用画笔（可调颜色/粗细）标注 |
| **非破坏性编辑** | 标注以矢量数据保存，**不修改**右侧原始截图 |
| **写回原图** | 右键「写入右侧」把标注扁平合成并覆盖原 PNG |
| **删除** | 左侧删除仅移除白板图片；右侧删除同时移除文件与白板引用 |
| **可移植** | 数据全部存放在软件目录，绿色运行 |
| **零依赖** | 不使用任何第三方 NuGet 包 |

## 构建与运行

进入项目根目录后执行：

```powershell
# 1) 构建 Debug（离线可用）
dotnet build Corkboard.sln
# 生成：bin\Debug\net8.0-windows\Corkboard.exe

# 或使用脚本
powershell -ExecutionPolicy Bypass -File setup.ps1
```

### 发布

```powershell
# 框架依赖单文件（约 2–5 MB，需目标机安装 .NET 8 Desktop Runtime）
powershell -ExecutionPolicy Bypass -File setup.ps1 -Publish

# 完全自包含单文件（约 140–160 MB，把 .NET 运行时一起打进去，免装运行时；首次发布需联网下载运行时包）
powershell -ExecutionPolicy Bypass -File setup.ps1 -Publish -SelfContained
```

> **为什么自包含版会大出一百多 MB？** 自包含发布会把整个 .NET 运行时（约 70 MB）和 WPF 框架一起塞进 exe，所以体积必然在 140 MB 以上；框架依赖版只打包你自己的程序集，因此只有几 MB，代价是目标机必须先装 .NET 8 Desktop Runtime。二者功能完全一样。

发布产物位于 `publish\Corkboard.exe`，数据文件会生成在 exe 同目录。

## 使用说明

### 全局快捷键

| 快捷键 | 默认值 | 作用 |
|---|---|---|
| 局部截图 | `Ctrl + Alt + A` | 全屏遮罩 → 拖拽框选 → 松手即存 |
| 全屏截图 | `Ctrl + Alt + S` | 立即截取主屏并保存 |

在顶部「设置」中点击输入框后按下组合键即可录制，`Esc` 取消。

**截图全程静默**：不弹任何确认框，也**不会把主窗口拉到前台**——即使窗口正处于最小化、或藏在其它程序后面，截完图依旧保持原样，不会打断你正在玩的游戏。截图会立即保存到当前分组并出现在右侧列表。

> 框选时按 `Esc` 可取消本次截图。

### 顶部工具栏

| 控件 | 作用 |
|---|---|
| 分组下拉框 | 切换当前分组 |
| 新建分组 / 重命名 / 删除分组 | 分组管理（删除有二次确认） |
| 添加便条 | 在白板上新建一张空白便条 |
| **清空白板** | **只清空左侧白板**（移除全部图片与便条），右侧截图列表与磁盘文件**不受影响**（有二次确认） |
| 设置 | 录制两个全局快捷键 |

### 分组管理

- 顶部下拉框切换当前分组；「新建分组 / 重命名 / 删除分组」按钮管理分组。
- 分组在磁盘上就是一个文件夹，删除分组会连同其中截图一并删除（有二次确认）。
- 每个分组**独立记忆**白板布局（图片/便条的位置、缩放、层级、笔画），切换或重启后原样恢复。

### 右侧缩略图列表

- 每张截图保存后进入右侧列表。
- **单击**列表项 → 该图片加入左侧白板（同一张可多次加入，各自独立标注）。
- **右键**列表项 → 「删除」：同时移除磁盘文件、列表项及白板上所有引用。

### 白板操作

| 操作 | 效果 |
|---|---|
| 拖拽图片/便条 | 移动位置 |
| 单击图片/便条 | 置顶（便条始终在图片之上） |
| 鼠标滚轮悬停图片 | 以鼠标位置为锚点缩放（0.1x–8x） |
| 双击便条 | 编辑文字；点击便条外部自动提交 |
| 顶部「清空白板」 | 移除左侧全部图片与便条（右侧列表与文件保留） |

### 图片编辑

1. 右键白板图片 → **编辑** → 打开独立编辑窗口（图片自动适应窗口大小居中显示）。
2. 顶部选择画笔**颜色**和**粗细**，直接在图片上绘制。
3. 点击「完成」或直接关窗 → 笔画**写回白板图片**（原始 PNG 未被修改）。

### 写回原图

右键白板图片 → **写入右侧**：把「原图 + 标注」扁平合成为 PNG 并**覆盖原始截图文件**，同时刷新右侧缩略图。此操作不可撤销。

### 右键菜单一览

| 位置 | 菜单项 | 作用 |
|---|---|---|
| 白板图片 | 编辑 | 打开编辑窗口 |
| 白板图片 | 写入右侧 | 标注固化并覆盖原图 |
| 白板图片 | 删除 | 仅从白板移除 |
| 列表项 | 删除 | 左右两侧一起删除 |

### 窗口与退出

- **点击窗口关闭按钮 → 直接退出程序**（自动保存白板、注销全局快捷键，进程完全结束）。
- **最小化窗口 → 普通最小化到任务栏**（不会被收进托盘；进程保留在后台，全局快捷键仍然可用）。
- 本程序**没有系统托盘图标**。

> 全局快捷键在程序运行期间一直有效——即使窗口最小化或不在前台。只有关闭程序才会注销快捷键。

## 数据存储

所有数据都保存在**软件（exe）所在目录**，整个文件夹可整体拷贝迁移：

```
<软件目录>/
├── Corkboard.exe
├── settings.json                 # 快捷键等配置
└── data/
    ├── store.json                # 分组、截图清单、白板布局、便条、笔画
    └── groups/
        └── <groupId>/            # 每个分组一个文件夹
            └── <itemId>.png      # 原始截图（唯一落盘的图片）
```

> 标注（笔画）以矢量数据存于 `store.json`，因此编辑**不会**改动原始 PNG；只有执行「写入右侧」才会覆盖它。

## 配置说明

`settings.json`（可直接编辑，也可在「设置」里改）：

```json
{
  "RegionHotkey": { "Modifiers": "Control, Alt", "Key": "A" },
  "FullScreenHotkey": { "Modifiers": "Control, Alt", "Key": "S" },
  "ImageFormat": "png"
}
```

- `Modifiers`：`None` / `Alt` / `Control` / `Shift` / `Win`，多个用逗号分隔。
- `Key`：WPF `Key` 枚举名，如 `A`、`S`、`F1`、`D1`、`OemPlus` 等。

## 代码结构

采用「**服务层 + 自定义控件 + 主窗口编排**」的轻量结构：

- `StoreService`：唯一的持久化出入口（JSON 与 PNG 读写）。
- `ScreenCapture` / `GlobalHotkeyService`：纯 P/Invoke 实现，无第三方依赖。
- `BoardCanvas`：白板容器，维护**图片层（z < 10000）**与**便条层（z ≥ 10000）**两套独立层级，保证便条恒在图片之上。
- `BoardImageControl`：单张白板图片，负责拖拽、置顶、锚点缩放、黑色边框与右键菜单。
- `AnnotationCanvas`：画笔标注层，坐标存于**图像原始像素空间**，因此缩放/写回后严格对齐。
- `MainWindow.xaml.cs`：集中编排分组切换、截图流程、白板读写与编辑窗口。

> 交互密集的白板部分使用自定义控件 + Code-behind（而非纯 MVVM），因为拖拽/缩放/命中测试天然由鼠标事件驱动，直接实现更清晰。

## 技术要点

| 需求 | 实现方式 |
|---|---|
| 屏幕捕获 | GDI `BitBlt` + `CreateBitmapSourceFromHBitmap` |
| 全局快捷键 | `RegisterHotKey` + `HwndSource.AddHook` 处理 `WM_HOTKEY` |
| 缩放锚点不漂移 | 左上角缩放 + 用白板绝对坐标补偿位置 |
| 命中区域随缩放 | 去掉控件透明背景，命中跟随缩放后的实际视觉范围 |
| 扁平合成写回 | `RenderTargetBitmap` 以原始像素分辨率渲染（不含边框） |
| 高 DPI | `app.manifest` 声明 `PerMonitorV2` |
| 异常兜底 | `App.xaml.cs` 捕获未处理异常并写入 `error.log` |

## 已知限制与常见问题

**已知限制**

- 全屏截图仅捕获**主屏**（多显示器不合并）。
- 编辑窗口为「适应窗口」显示，暂不支持在编辑窗口内滚轮缩放。
- 白板空间固定为窗口大小，图片拖出可视区域不会自动出现滚动条。
- 缩放后不会自动把图片位置约束回白板范围内。

**常见问题**

- **运行时提示「Windows 已保护你的电脑」/「未知发布者」（SmartScreen）**
  这是**未做代码签名**的正常现象，与应用本身安全与否无关：SmartScreen 只看「数字签名 + 下载声誉」，不看代码在做什么。点「更多信息 → 仍要运行」即可。
  想彻底消除：① 购买代码签名证书（EV 证书可立即获得声誉）；② 右键 exe → 属性 → 勾选「解除锁定」，消除「来自 Internet」标记。
  本应用涉及屏幕捕获与全局热键，这类行为在启发式扫描里比普通小工具更容易被提示，但源码就在本目录，可自行审阅。

- **发布的自包含单文件无法运行**
  优先使用框架依赖发布（`setup.ps1 -Publish`，本机需装 .NET 8 Desktop Runtime）。若仍失败，请查看 exe 同目录下的 `error.log`。

- **`NU1900 无法加载源 nuget.org` 警告**
  本项目零第三方包，该警告只是离线查不到漏洞数据库，可忽略。

- **快捷键不生效**
  可能与其他软件冲突。到「设置」里换一组组合键。

- **想换数据目录 / 备份**
  直接拷贝整个软件目录即可；`data/` 与 `settings.json` 就是全部数据。

## 重新生成图标

图标由脚本绘制生成（软木板 + 照片 + 图钉）：

```powershell
powershell -ExecutionPolicy Bypass -File make-icon.ps1
```

会输出 `Assets/Corkboard.ico`（exe 图标）与 `Assets/Corkboard.png`（预览）。修改脚本中的绘制参数即可调整样式，之后重新构建生效。
